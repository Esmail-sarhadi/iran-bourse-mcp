# Getting help

- **A tool fails or returns odd data?** Run `iran-bourse-mcp doctor` and open a [bug report](https://github.com/msmahdinejad/iran-bourse-mcp/issues/new?template=bug_report.yml) with its output. TSETMC changes without notice, so this is the most useful report you can send.
- **Cannot connect from your agent?** See the install recipe for your client: `iran-bourse-mcp config <client>`, or the [website](https://msmahdinejad.github.io/iran-bourse-mcp/#install).
- **Foreign IP or VPN problems?** Read [The Iranian IP requirement](README.md#the-iranian-ip-requirement).
- **Want a new tool or field?** Open a [feature request](https://github.com/msmahdinejad/iran-bourse-mcp/issues/new?template=feature_request.yml) and describe the question you want your agent to answer.
- **Security issue?** See [SECURITY.md](SECURITY.md).

This is a volunteer project. There is no SLA, and nothing here is investment advice.
